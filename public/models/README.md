# Resonance music environments

Run `node scripts/build-music-world.mjs` for the glass pavilion and shared equipment. Run `node scripts/build-music-scenes.mjs` for the vinyl studio and live stage shells. Version 3 separates the architecture from the equipment so changing scenes retains the player, archive interactions and seating. The central control terminal includes a modeled housing, inclined touchscreen, supports and ventilation slots. All geometry is authored programmatically for this project with PBR materials; no external model licenses are required.
